# ClaimLens Backend

A Python-based backend for AI-assisted academic paper understanding.

## Features

- Academic HTML processing (ACM, IEEE, arXiv, Springer)
- Claim and Evidence extraction
- Evidence retrieval and argument Mapping
- Source-grounded analysis
- Read-only API for frontend integration

## Tech Stack

Python, LangGraph, OpenAI API, FastAPI, and uv.

## Status

Under development. The backend is being integrated with the frontend.
